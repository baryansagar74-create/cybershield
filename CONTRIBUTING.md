# Contributing to ProfileGuard

Thank you for contributing to ProfileGuard.

## Code Standards
- Python 3.11+ strictly typed with type hints.
- Code formatted with standard black/flake8 conventions.
- Never hardcode credentials, tokens, or personal identifiers.
- All legal citations must be marked `# CONFIRM WITH LEGAL`.

## Reporting Vulnerabilities
Do NOT open public GitHub issues for security vulnerabilities.
Direct sensitive reports securely to the ITBP Cyber Command at `cyber-security@itbp.gov.in`.
